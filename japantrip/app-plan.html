1. Purpose and Target Audience

Site Name

JapanTrip Explorer (Folder: japantrip)

Purpose

The purpose of JapanTrip Explorer is to provide an interactive, mobile-first web application that helps travelers discover iconic destinations across Japan and build a realistic daily trip itinerary with live budget estimation. Users can search, filter, and sort curated destinations on the Home page (index.html), inspect travel tips and admission costs in an accessible modal dialog, and use the second page (planner.html) to add stops to a custom schedule and calculate total estimated expenses.

Target Audience

  • Primary Audience: First-time international travelers, college students, and study-abroad visitors aged 18–45 planning a self-guided trip to Japan.
  • User Needs: Quick access to organized destination data by region (Kanto, Kansai, Chubu, Hokkaido) and category (Culture, Nature, Food, City), clear cost estimates in Japanese Yen (¥), and a lightweight itinerary budget calculator that works seamlessly on smartphones while traveling.

2. Dynamic Elements (JavaScript Plan)

JavaScript will power both pages of the application using modular, reusable functions, structured data objects, array methods, DOM manipulation, event listeners, and conditional logic:

Data Structures (Objects & Arrays)

  • destinations Array of Objects: Each object stores id, name, region, category, tags (array of strings), estimatedCost (number), rating (number 1–5), image, imageAlt, description, and travelTip.
  • itinerary Array of Objects: Stores user-selected trip stops (id, name, day, category, cost) to dynamically render and calculate the trip schedule.

Array Methods Used

  • .filter() & .find(): Filter the destinations array by matching search keywords against name, description, and tags, as well as dropdown selections for region and category.
  • .sort(): Reorder filtered destinations alphabetically by name (A–Z) or numerically by rating (high to low) and estimated cost (low to high).
  • .map() & .forEach(): Transform destination objects and tag lists into HTML template literal strings and render each card into the DOM container.
  • .reduce(): Calculate the total estimated cost of all stops in the user's itinerary on the Planner page (itinerary.reduce((total, stop) => total + stop.cost, 0)).

DOM Manipulation, Events & Conditional Branching

  • DOM Selection & Updates: Use document.querySelector() and document.getElementById() to update card grids, modal content, budget counters, and ARIA attributes (aria-expanded, aria-live="polite").
  • Event Listeners: Listen for form submit (using e.preventDefault()), search input, filter/sort change, navigation menu click, and card action button clicks.
  • Conditional Logic (if / else):
    1. Check if filtered search results are empty (filtered.length === 0) to display a friendly "No matching destinations found" message.
    2. Compare total itinerary cost against the user's budget limit (if (totalCost > budgetLimit)) to toggle warning styles and alert messages dynamically.
    3. Validate form inputs (non-empty destination, valid day number and positive budget) before adding a stop.

3. Pseudocode & Computational Thinking

Feature A: Destination Filtering, Sorting & Rendering (Home Page)

1. DEFINE `destinations` array with 8+ objects.
2. SELECT DOM elements:
   - `gridContainer` (#destination-grid)
   - `searchForm` (#filter-form)
   - `searchInput` (#search-input)
   - `regionSelect` (#region-select)
   - `sortSelect` (#sort-select)
   - `detailDialog` (#detail-dialog)

3. FUNCTION tagTemplate(tags):
   - MAP each `tag` in `tags` to `<li>${tag}</li>` and JOIN("").

4. FUNCTION ratingTemplate(rating):
   - INITIALIZE `html` with `<span role="img" aria-label="Rating: ${rating} out of 5 stars">`
   - LOOP `i` from 1 to 5:
     - IF `i <= rating`, APPEND filled star span
     - ELSE APPEND empty star span
   - RETURN closed span HTML string.

5. FUNCTION destinationCardTemplate(dest):
   - RETURN `<article class="dest-card">` containing image, region badge,
     name, ratingTemplate(dest.rating), estimatedCost, tagTemplate(dest.tags),
     and a "View Details" button with `data-id="${dest.id}"`.

6. FUNCTION renderDestinations(list):
   - CLEAR `gridContainer.innerHTML = ""`
   - IF `list.length === 0`:
     - SET `gridContainer.innerHTML` to no-results message and RETURN.
   - FOREACH `item` in `list`:
     - APPEND `destinationCardTemplate(item)` to `gridContainer`.

7. FUNCTION filterAndSort(event):
   - IF `event` exists, CALL `event.preventDefault()`
   - READ `query` = `searchInput.value.trim().toLowerCase()`
   - READ `region` = `regionSelect.value`
   - READ `sortBy` = `sortSelect.value`
   - FILTER `destinations` into `filtered`:
     - `matchesQuery` = name, description, or tags.find() includes `query`
     - `matchesRegion` = (region === "all") OR (dest.region === region)
     - RETURN `matchesQuery && matchesRegion`
   - SORT `filtered`:
     - IF `sortBy === "name"`, compare `a.name` vs `b.name`
     - ELSE IF `sortBy === "cost-asc"`, return `a.estimatedCost - b.estimatedCost`
     - ELSE IF `sortBy === "rating-desc"`, return `b.rating - a.rating`
   - CALL `renderDestinations(filtered)`

8. INITIALIZE page on load by calling `renderDestinations(destinations)`.

Feature B: Itinerary Builder & Budget Calculator (Second Page)

1. INITIALIZE `itinerary` array with sample stops.
2. SELECT DOM elements:
   - `plannerForm` (#planner-form)
   - `destSelect` (#dest-select)
   - `dayInput` (#day-input)
   - `budgetInput` (#budget-input)
   - `itineraryList` (#itinerary-list)
   - `totalCostEl` (#total-cost)
   - `budgetStatusEl` (#budget-status)

3. FUNCTION calculateBudgetSummary():
   - USE `.reduce()` on `itinerary` to compute `totalCost`:
     `const totalCost = itinerary.reduce((sum, stop) => sum + stop.cost, 0)`
   - READ `budgetLimit` = Number(budgetInput.value) || 20000
   - UPDATE `totalCostEl.textContent` with formatted Yen amount
   - IF `totalCost > budgetLimit`:
     - SET `budgetStatusEl.textContent` = "Over Budget by ¥" + (totalCost - budgetLimit)
     - ADD class "status-over" and REMOVE "status-ok"
   - ELSE:
     - SET `budgetStatusEl.textContent` =
       "Within Budget (¥" + (budgetLimit - totalCost) + " remaining)"
     - ADD class "status-ok" and REMOVE "status-over"

4. FUNCTION handleAddStop(event):
   - CALL `event.preventDefault()`
   - FIND selected destination object in `destinations` using `.find()`
   - VALIDATE inputs with `if / else`; if invalid, display error message and RETURN
   - PUSH new stop object `{ id, name, day, category, cost }` into `itinerary`
   - CALL `renderItinerary()` and `calculateBudgetSummary()`

4. Style Guide (Colors & Typography)

Colors are chosen to evoke traditional Japanese indigo (Ai-iro) and vermilion (Shu-iro) while maintaining WCAG AA/AAA contrast ratios for a 96+ Lighthouse Accessibility score.

Primary: #1D3557 (Deep Indigo)
Secondary: #457B9D (Steel Blue)
Accent: #C1121F (Torii Crimson)
Background: #F8F9FA / Text: #1B263B

Heading Font: Montserrat (700 Bold / 600 SemiBold) — clean geometric sans-serif for titles and cards.
Body Font: Open Sans (400 Regular / 600 SemiBold) — highly legible body copy across mobile and desktop screens.
